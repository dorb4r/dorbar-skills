# 03_script: the beat sheet

One job: turn the picked idea into a beat table that works on mute and names a source per row.

## Inputs
- Working: `{run}/01_brief.md`
- Working: `{run}/02_ideas.md` (the pick only)
- Reference: `../../references/script.md`
- Reference: `../../references/hooks.md`
- Example: the one `../../examples/<id>.md` the pick borrows from
- Project: `{project}/references/brand.md` (voice and words)

Do NOT load: music, editing or CapCut references; past runs.

## Process
1. Premise sentence, emotion, sender; then the last line, then the hook, then the middle (`script.md`).
2. Beat table with times, picture, spoken/VO, on-screen text, sound, emotion. Each row's source is an
   existing file (path + in-point) or `TO SHOOT: <shot>`.
3. Text in the project's language and voice. Speech lines are what the person would really say;
   mark them for the person to reword.
4. Run the script check (`script.md`) and the hook checklist (`hooks.md`); write the results under the table.

## Outputs
- `{run}/03_script.md`

## Check
Human check: the owner approves the script (and the speaker approves their lines).
